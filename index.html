    Connecting the Shuffle project to Vercel.

    Steps to connect your project to Vercel.

    1. Point to the Git repository following the instructions on the previous screen.
    2. Export your project to Git.
    3. Switch to Vercel and add a new project, selecting the same repository.
    4. Set up the project name and click deploy. No changes in other fields are needed.
    5. In a few seconds, your project will be available at the URL provided by Vercel.

    Add new connection

    Please insert this public key into your server's ~/.ssh/authorized_keys file, then fill out the remaining form fields and click Save connection. (show detailed help).

    Copy the public key from the text area provided above. Ensure you select the entire key. Access your server where you intend to add this public key. Once logged in, navigate to the appropriate directory where SSH keys are stored.

    This is commonly located within the .ssh directory in the home directory of your user account. Open the authorized_keys file in a text editor. If the file does not exist, you may need to create it. Paste the copied public key into this file.

    Ensure it is pasted as a single line and that no line breaks or additional characters are added. Save the changes to the authorized_keys file and exit the text editor. After successfully inserting the public key into your server, return to this page, complete the remaining form fields, and click Save connection.

    1. Add the Shuffle MCP server

      Run this command in your terminal:

      claude mcp add --transport http shuffle https://shuffle.dev/mcp

    2. Sign in to Shuffle

      Start Claude Code, run /mcp, select shuffle and choose to authenticate. Your browser opens Shuffle: log in and click Allow.

    3. Ask for a design

      Start your message with “Use Shuffle to…” or use the /mcp__shuffle__design and /mcp__shuffle__redesign commands, so Claude Code uses Shuffle instead of writing the code itself. For example:

      • Use Shuffle to design a landing page for a specialty coffee roastery in Berlin, with a menu, opening hours and table booking. Warm, earthy colors.

      • Use Shuffle to design a landing page for the app in this repository, then download the Claude design into the ./site folder.

    Use Shuffle in other coding agents

    The Shuffle MCP server works with any app that supports remote MCP servers. Use this server URL everywhere:

    https://shuffle.dev/mcp
    Cursor

    Add the server to ~/.cursor/mcp.json (all projects) or .cursor/mcp.json in your project. Then open Cursor Settings → MCP, find shuffle and click Login or Connect to sign in.

    {
  "mcpServers": {
    "shuffle": {
      "url": "https://shuffle.dev/mcp"
    }
  }
}
    VS Code

    Add the server to .vscode/mcp.json in your project, or run MCP: Add Server from the Command Palette and choose HTTP. Start the server, follow the sign-in prompt and use Copilot Chat in agent mode.

    {
  "servers": {
    "shuffle": {
      "type": "http",
      "url": "https://shuffle.dev/mcp"
    }
  }
}
    Claude (web & desktop)

    Open Settings → Connectors and choose Add custom connector. Name it Shuffle, paste the server URL, click Connect and sign in. In a chat, make sure the Shuffle connector is enabled in the tools menu.

    https://shuffle.dev/mcp
    Other MCP clients

    Any app that supports remote MCP servers with OAuth can connect. Add a server with this URL and the HTTP (Streamable HTTP) transport; sign-in is discovered automatically. Apps that only support local (stdio) servers can connect through a bridge such as mcp-remote.

    https://shuffle.dev/mcp
